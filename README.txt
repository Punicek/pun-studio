PUN STUDIO – WEB PRO GITHUB PAGES

Struktura:
/index.html – hlavní web Pun Studio
/projekty/johnny/index.html – web Johnny Annihilator včetně zombici.mp4
/projekty/medieval/index.html – web Medieval RTS včetně assets

Všechny tři odkazy v sekci Naše projekty se otevírají v nové záložce.
Frontier Command vede na https://punicek.github.io/frontier-command/
Johnny a Medieval jsou samostatné stránky v rámci stejného webu.

Publikace na GitHub Pages:
1. Vytvořte repozitář pun-studio na účtu punicek.
2. Nahrajte obsah ZIP do kořene repozitáře (index.html a složku projekty).
3. V Settings > Pages nastavte Deploy from a branch: main, /(root).
4. Adresa pak bude https://punicek.github.io/pun-studio/

POZOR: Formulář je pouze testovací. Nic neodesílá. Před spuštěním pro klienty je potřeba
napojit doručování poptávek a vyřešit zásady ochrany osobních údajů.
